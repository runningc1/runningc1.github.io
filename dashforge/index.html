Dashforge: permutations for review

One simulated company (Northpeak Software, 90 days, pre-generated). Every page builds a dashboard for whatever role you type, from the same data. Pages differ only in which features are on; every page has a Features row where you can flip any of them, so these are starting points, not walls.

Permutation 1

Lean

The four I would ship first under a timer.

  • Role chips (same world, other seat)
  • Time scrubber over 90 days
  • Alerts that point to a chart
  • KPI drill-down, live alert after render
  • Tables: sort and filter on every column
 Permutation 2

Story

Lean plus the two cheap axiom-sellers.

  • Story ribbon: both events on every dashboard, lit or dimmed by role
  • Reconciliation footer: same numbers on every page
 Permutation 3

Flow

Story plus the one picture that is the axiom.

  • Marketing to sales to support band diagram on top of every dashboard
 Permutation 4

Full

Everything, including the alternate chart forms and control dimming.

  • Bullet bars, small multiples, ARR waterfall, arrival heatmap, CPL slope, rep dot strip (swapped in per role)
  • Charts outside the role's control render dimmed

How to practice prompting here

  1. Type a role in the box (or click an example). The local planner builds the dashboard with no network call.
  2. Open "Agent prompt" at the bottom. That is the exact prompt the server sends to the model, with the data digest as of the scrubber date.
  3. Copy it into Claude, paste the JSON reply back, click Render. Or enter an API key in the optional box to call the model directly from the browser (key stays in memory).
  4. Deep link a request: lean.html?q=support%20agent. Deep link features: #flow=1&altForms=1.

What is deterministic and what the model decides

  • Engine (world.json): every number, series, table row, and alert. Two injected events: paid CPC spike on day 45, v4.2 release on day 63.
  • Model or fallback planner: role card, which KPIs and blocks, layout widths, insight text, what was left off and why, which alert domains are in focus.
